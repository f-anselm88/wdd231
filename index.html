About Me

I'm a junior full-stack developer based in Windhoek, Namibia, originally from the Kavango region and a native Rukwangali speaker. I'm currently pursuing a BS in Software Development through BYU-Idaho and BYU-Pathway Worldwide, working across React, JavaScript, C#, Python, and REST APIs.

Before development, I spent two years serving a mission in Ghana — work that shaped how I approach problems now: patiently, cross-culturally, and with an eye for what actually helps people. That same instinct drives my flagship project, a language-learning platform built to keep Rukwangali alive for the next generation of speakers.

I also run The Catalist, a small advertising and retail business, which keeps me fluent in shipping real products for real clients — not just coursework.

What I'm Building

Eraka Lyetu

A full-stack Rukwangali language-learning platform built with React and Vite. It uses the SM-2 spaced-repetition algorithm, Web Speech API pronunciation practice, an AI tutor powered by the Anthropic API, and a bilingual Gospel of John reading section — with XP, streaks, and leaderboards to keep learners coming back.

React · Vite · Web Speech API · Anthropic API
