Images

All destination illustrations, the favicon and the social sharing image are original vector artwork created by Anselm Munango for this project. No third-party photographs are used.

Code and fonts

The site uses plain HTML, CSS and JavaScript. No frameworks, templates or libraries are used, and text is set in the visitor's system fonts.

Content

Destination descriptions were written in the author's own words from publicly available information about Namibia. Twyfelfontein's World Heritage status is recorded by the UNESCO World Heritage Centre.
